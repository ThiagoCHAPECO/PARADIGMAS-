# COBOL

## Sobre a linguagem

**COBOL (Common Business-Oriented Language)** foi criado em **1959** pelo grupo CODASYL e teve sua primeira versão lançada em **1960**. Surgiu principalmente para atender à necessidade de uma linguagem voltada para processamento de dados empresariais, que pudesse ser utilizada em diferentes computadores e sistemas.

## As 4 Divisões do COBOL

* **IDENTIFICATION DIVISION:** identifica o programa e fornece suas informações básicas.
* **ENVIRONMENT DIVISION:** define o ambiente e os recursos externos utilizados pelo programa.
* **DATA DIVISION:** declara e organiza as variáveis e estruturas de dados utilizadas.
* **PROCEDURE DIVISION:** contém a lógica e as instruções que serão executadas pelo programa.
